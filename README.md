# 🌐 Full-Stack IoT System (ESP32-C3 + Mosquitto + FastAPI + Vue 3)

基于 **ESP32-C3 RISC-V 核心板**、**Eclipse Mosquitto (MQTT Broker)**、**Python FastAPI 后端** 与 **Vue 3 可视化看板** 构建的端到端物联网监控与远程控制闭环系统。

本项目打通了 **底层硬件驱动 ➔ 物联网消息协议 ➔ 后端数据持久化 ➔ 前端动态看板与反向控制** 的完整技术链路，提供从 0 到 1 的全流程复现指导。
